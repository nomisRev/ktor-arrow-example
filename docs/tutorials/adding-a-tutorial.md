# Adding a tutorial

Use this page as a template for new tutorial entries.

## Recommended shape

- explain the goal first
- keep one task per page
- include code snippets only when they support the explanation
- link forward to the next page so the reader can continue

## Example

1. Introduce the topic.
2. Show the file or command to change.
3. Explain the result.
4. Link to the next tutorial or the reference page.

!!! note
    If a tutorial becomes too long, split it into multiple pages and add them to `mkdocs.yml`.
